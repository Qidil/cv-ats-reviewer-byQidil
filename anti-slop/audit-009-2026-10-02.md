## 1. Owner instruction (R-23 satisfied)

"saya mau dibuatkan logo untuk dipasang di header, icon web, dan di footer, untuk logonya itu gabungan stetoskop dokter + tulisan CV, dalam format svg saja". Explicit instruction, so no clarification was needed. Direction: `project-context/StyleGuide.md` section 8.

## 2. Reasons for the main decisions (R-31)

| Decision | One-line reason |
| --- | --- |
| One stethoscope that spells C and V | The owner asked for a stethoscope plus the letters CV; one continuous object is more specific to the product than a symbol next to a font. |
| Letters as paths, no `<text>` | No font dependency, identical rendering in a tab, an `<img>`, and any browser. |
| Ink `#1A1A1A` strokes, one `ink-teal` accent on the diaphragm | StyleGuide 8.1/8.1b palette; the accent sits on the one part that reads as "the instrument". |
| Favicon: ink tile, paper strokes, `marker-wash` diaphragm | A transparent ink mark vanishes on dark tabs; teal on the ink tile is too dark; `marker-wash` is the product's own highlighter token. |
| Heavier strokes in the favicon | Survives at 16 px (viewed at 16/32/64/128 px on light and dark backdrops). |
| Decorative image, `alt=""` | The product name stays real text beside it; a second accessible name would be noise. |
| Crisp geometry, not hand-drawn wobble | Legibility at 16 px beats imitation of the sketch style; the hand-drawn feel lives in the UI chrome around it. |

## 6. Observations (not violations)

1. **Favicon tile on dark tabs, 1.08:1.** The tile edge disappears against `#202124`; the strokes inside stay 16.42:1, so the mark still reads. P3.
2. **Inline hex in the SVGs.** Values are tokens today; drift is possible if the palette changes. P3.
3. **Crisp geometry beside a hand-drawn UI.** Deliberate (section 2). If the owner wants more sketch character, add slight irregularity to the paths in the page logo only and keep the favicon geometric.
4. **No `PRODUCT.md` for Impeccable.** The audit proceeded on the incumbent implementation; `$impeccable init` can capture product context if wanted.
